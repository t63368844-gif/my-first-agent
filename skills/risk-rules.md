# Risk Rules (обязательны к соблюдению)

1. Одна сделка ≤ 1% депозита (при 50 000 USDT это ≤ 1000 USDT).
2. Перед ордером: показать пользователю символ, сторону, сумму в USDT и ждать явного «да».
3. Не более 3 ордеров в одной сессии чата без паузы.
4. После каждой покупки проверять баланс getBybitBalance и сверять арифметику.
5. Никогда не продавать весь баланс base coin за один ордер (максимум 50% позиции).
6. При ошибке retCode != 0 НЕ повторять ордер автоматически — сообщить пользователю.
7. Все операции только на demo-домене; реальный аккаунт физически недоступен.
